필수 태그
	<!DOCTYPE html>		HTML5 문서임을 알리는 지시어
  <html></html>			시작과 끝
  <head></head>			문서 제목이나 여러 정의들
  <title></title>		문서 제목
  <body></body>			문서의 본문 텍스트, 이미지, 콘텐츠 등
  
태그
	<h1></h1>~<h6></h6>	문단 제목 (1~6까지)
  <h1 title="툴팁">		툴팁 달기 (마우스 올리면 툴팁 출력)
  <p></p>							단락 나누기
  <hr>								수평선
  <br>								줄 넘어가기
  <pre></pre>					포맷 그대로 출력

블록 태그		- 항상 새 라인에서 시작하여 출력
							양 옆에 다른 콘텐츠를 배치하지 않고 한 라인 독점 사용
							ex) <div></div>

인라인 태그	- 블록 속에 삽입 되어 블록의 일부로 출력
							ex) <span>

텍스트 꾸미기
  <b>문자</b>						진하게
  <strong>문자</strong>	중요한
  <em>문자</em>					강조
  <i>문자</i>						이탤릭으로 강조
  <b><i>문자</i></b>		진하게 이탤릭으로 강조
  <small>문자</small>		한 단계 작은 문자
  <del>문자</del>				삭제
  <ins>문자</ins>				추가
  <sup>문자</sup>				윗첨자
  <sub>문자</sub>				아래첨자
  <mark>문자</mark>			하이라이팅

특수 문자, 기호, 심볼		- &엔터티; or &#코드값;
